## 최신 버전 (R11~14) 규칙 — 복원한 것
경제
1. **T1: `UPGRADE HQ` (600)**. A1은 **중앙 거점(N-1)/2 로 이동해 눌러앉음** (적의 중앙 기지 건설 차단 + 중앙 시야). A2,A3는 HQ 노동(L2 = 2슬롯).
2. 이후 **가까운 빈 거점부터** (경로길이 순위 0~2) 1명씩 보내고 골드 500 되는 턴에 건설. T21, 38, 51, 61, 71, 79, 86, 101 … 약 10턴 간격. 건설 전 골드는 늘 500~570 (딱 맞춰 씀).
3. 기지는 전부 **L1, 노동자 1명**. HQ 노동자가 떠나면 같은 턴에 `TRAIN 1` 로 즉시 보충 (전사 수 = 노동슬롯 + 점령자 1 + 정찰 1).
4. **HQ L3 (1000)** 은 기지 5~7개일 때 / T87~96. 저축 중엔 점령 멈춤.
5. T~105부터 **매 턴 1~2명 훈련** (골드 150~600 유지). 스카우트 1명은 T70~78에 적 본부 1~2홉 지점에 상주.
6. 기지 L2 는 T111부터 후방부터 드문드문, T200~250 에 일괄 L2→L3. HQ L4/L5 는 T160~280 (골드 쌓일 때). R14: T228에 거점 19개 전부 보유, T272 전부 L3, T280 HQ5, T290~ 3명/턴 → 123기 → T307 본부 파괴.

군사
7. 병력은 **전방 기지(적 본부까지 8~10홉)** 에 집결(무료 이동). 시야에 들어온 적 기지(L1/L2, 수비 1~2)에 **4~11명 소규모 습격**을 반복 (실패해도 재시도). 우리 기지가 L3 화 되기 전(T121~138)에 이걸로 inhyuk 의 기지를 다 부수고, 반격 온 inhyuk 11기는 돌 기지(수비 4 + 증원 8 + 포탑)에서 전멸.
8. 큰 적 스택이 오면 후방 기지로 후퇴(무료 이동). 본부 수비는 노동자 3명뿐 — 본부가 직접 공격당한 판이 없어 검증 안 됨.
9. 강한 상대(R13, inhyuk_v4 L3 기지 7~9개)에겐 습격이 안 먹혀 무승부 (양쪽 본부 30/30).

## 복제 결과 (TEAM/v7_dol.cpp = v5 인프라 + 위 규칙)
- vs sample 4/4, vs v6 0승 2무 2패, **vs inhyuk_v6 1승 2무 7패** (seed 100~109).
- 이유: 로컬에서 inhyuk_v6 는 T125에 기지 전부 L3 + 수비 3 → 습격 불가. 순수 매크로 경쟁에서 L1 스팸(수입 T150 ≈ 195)이
  inhyuk 의 L3 집중(≈270, HQ4/5 빠름)에 밀리고 T175 병력 39 vs 54, T250 35 vs 110.
- 대회에서 돌이 inhyuk_v6 를 이긴 것은 그 판에서 inhyuk 기지가 T121 에 아직 L2 였고 습격이 통했기 때문 (R14 로그). R13 처럼 습격이 막히면 무승부.
